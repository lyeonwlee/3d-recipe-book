# 3D Recipe Book

크라프트 파일 안의 책, WANTED 포스터, 양면 팸플릿, A6 판결문과 공범 관계도를 볼 수 있는 3D 웹 프로젝트입니다.

## 웹사이트

https://recipe-book-yeonwoo.amber-harp-5613.chatgpt.site

## 실행

루트의 index.html이 배포용 진입점입니다.

```sh
python3 -m http.server 4173
```

http://localhost:4173 으로 접속합니다. 별도 빌드나 설치가 필요하지 않습니다.

## 원본 프로젝트 폴더

브라우저 업로드를 위해 배포 파일은 저장소 루트에 배치했습니다. 원래 폴더 구조와 소스는 `recipe-book-source.zip`에 그대로 포함되어 있습니다.

## 조작

- 파일 왼쪽 빈 면 클릭: 파일 접기/펴기
- 자료 클릭: 3D로 꺼내 보기
- 책 클릭: 페이지 넘김
- 양면 자료 클릭: 앞뒷면 전환
- 드래그/스크롤: 각도 조절
- 검은 배경 클릭 또는 Escape: 파일로 돌아가기
- 공범 관계도: 트랙패드로 이동, 핀치로 확대/축소, 드래그로 회전, 0으로 시점 복원

디자인과 이미지의 권리는 원저작자에게 있습니다.
